# Regression fixtures (Python reference v1 → C++/ESP32)

Generated by `python scripts/make_fixtures.py` from the frozen v1 reference
(`docs/reference_v1.md`). The C++ decoder must reproduce these outputs **trial by trial**;
matching overall accuracy is not enough (two decoders can both score 96 % yet disagree on
individual windows).

## Layout

| Path | Committed | Contents |
|---|---|---|
| `config/synapsys_v1.json` | yes | Frozen embedded config: 60/7, 12, 15 Hz; O1/Oz/O2/POz; 250 Hz; 625-sample window; 2 harmonics; **exact SOS coefficients** (0.5–45 Hz Butterworth + 60 Hz notch); CCA and decision rules |
| `config/benchmark_v1.json` | yes | Same decoder at 8/12/15 Hz, no notch (matches the Wang validation) |
| `synthetic/<id>/` | yes | 12 seeded streams: clean/noisy per command, noise only, ambiguous mixture, off-target, heavy 60 Hz, ±300 mV DC offsets, dead channel, flat (degenerate) |
| `wang/<id>/` | **no** (git-ignored) | 8 real Wang 2017 trials (S1–S3): both misclassified trials, lowest-margin correct, median-margin correct. Regenerate locally: `fetch_benchmark.py 1 2 3` then `make_fixtures.py`; `MANIFEST.json` hashes prove the regenerated files are identical |
| `MANIFEST.json` | yes | SHA-256 of every file + generator git revision |

## Per-fixture files

- `raw.csv` — header = channel names; one row per sample; **volts**, `%.17g` (exact float64
  round trip). Expected outputs were computed from the values read back from this file.
- `filtered_<config>.csv` — causal filter output for the whole stream (same layout).
- `expected.json` — per config, a list of decision points. Each has
  `window_start_sample`/`window_end_sample` (625 samples, end exclusive), `scores`
  (largest canonical correlation per target), `all_correlations`, `winner`,
  `winner_frequency`, `confidence`, `margin`, `decision_ungated`, and `gated_test_only`
  (decisions for a 3×3 grid of **test-only** thresholds T ∈ {0.2, 0.3, 0.4},
  M ∈ {0.02, 0.05, 0.1} — exercises REJECT; these are NOT calibrated thresholds).
  A point with `"error": "DegenerateSignalError"` means the decoder must report an explicit
  degenerate-input error (never NaN, never a command).

## Processing contract (what the C++ must do)

1. Per channel: subtract the **first sample of the stream**, then run the SOS cascade
   (direct form II transposed, `scipy.signal.sosfilt`) from zero state.
2. Decision points every 125 samples once 625 samples exist (Wang fixtures add the
   benchmark window ending at sample 785).
3. Window = last 625 filtered samples. References restart at t = 0 for every window
   (`sin/cos(2π·h·f·n/fs)`, n = 0..624, h = 1..2), so they are constant tables.
4. CCA: Björck–Golub principal angles (see `config/*.json` → `cca`). No covariance
   inversion, no regularisation.
5. Winner = max score, ties → first target in config order; margin = winner − runner-up.

## Acceptance criteria (C++ vs these fixtures)

| Quantity | Criterion |
|---|---|
| Filtered samples | max abs error within a tolerance fixed after measuring float32 vs float64 (target ≤ 1e-3 of signal RMS) |
| Each CCA score | abs error < 1e-3 |
| Margin | abs error < 1e-3 |
| Winner | 100 % agreement on every decision point |
| Ungated and test-threshold decisions | 100 % agreement, except points whose score/margin lies within 1e-3 of a test threshold (reported, not silently passed) |
| Degenerate points | explicit error reported at exactly the same points |
